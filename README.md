# Тестовое задание CAD-эксперта (жёсткая фланцевая муфта)

Решение тестового задания на вакансию **SolidWorks / FreeCAD / Siemens NX CAD Expert**.

Суть задания: придумать задачу на изменение сборки, рассчитанную на 2–6 часов
работы инженера, выполнить это изменение на параметрической сборке и приложить
чек-лист проверки — всё упаковать в требуемую структуру папок `takehome/`.

- **CAD-система:** FreeCAD 1.1.x (нативные файлы `*.FCStd`).
- **Переносимый формат:** каждая деталь и сборка дополнительно экспортированы в
  **STEP** (`*.step`), поэтому модель открывается и в SolidWorks / Siemens NX.

## Задача в одну строку

Жёсткая фланцевая муфта должна передавать больший крутящий момент в том же
габарите, поэтому болтовое соединение переводится **с 4 болтов на 6** на той же
окружности центров Ø90 мм — управляется **параметрически** одним значением
`bolt_count`. Полное описание — в [`takehome/task.txt`](takehome/task.txt),
критерии приёмки — в [`takehome/checklist.txt`](takehome/checklist.txt).

> Файлы `task.txt` и `checklist.txt` оставлены на английском языке, так как этого
> требует само задание (текст задачи должен быть на английском).

## Структура пакета

```
takehome/
├── task.txt            # задача (зачем + что + ограничения)
├── checklist.txt       # чек-лист проверки (допускает разные верные решения)
├── Defective/          # пустая (по требованию задания)
├── Before/             # исходная модель — 4 болта
│   ├── input.FCStd         # сборка верхнего уровня (ссылается на детали)
│   ├── input.png           # скриншот
│   ├── input.step          # экспорт в STEP
│   ├── flange_half.FCStd   # параметрическая деталь + .step
│   ├── bolt_m10.FCStd      # деталь + .step
│   └── nut_m10.FCStd       # деталь + .step
└── After/              # решение — 6 болтов
    ├── solution.FCStd
    ├── solution.png
    ├── solution.step
    └── ... те же детали ...
```

## Как воспроизвести модель

Весь пакет генерируется скриптами (сквозная параметрика):

```bash
# нужны установленный FreeCAD 1.1.x, а также python3 + numpy + matplotlib
./scripts/make_takehome.sh
```

- `scripts/build_coupling.py` — скрипт для FreeCAD; строит параметрические детали
  и сборку для заданного `bolt_count` (4 для *Before*, 6 для *After*),
  экспортирует FCStd + STEP + сетку.
- `scripts/render_png.py` — рендерит изометрические скриншоты из сетки.
- `scripts/make_takehome.sh` — запускает оба и собирает `takehome.zip`.

## Почему это задача на 2–6 часов

Это реальное изменение требований (больше крутящего момента при фиксированном
габарите), а не тривиальная правка размера: инженеру нужно переработать болтовой
узор на обоих сопрягаемых фланцах, сохранить соосность отверстий и симметрию
относительно шпоночного паза, заново расставить болты и гайки, оставить всё
остальное неизменным и убедиться, что модель по-прежнему корректно
перестраивается параметрически без битых ссылок.
