# CAD Expert — Take-Home Assignment (Rigid Flange Coupling)

Submission for the **SolidWorks / FreeCAD / Siemens NX CAD Expert** take-home.

The assignment: invent a 2–6 hour assembly-change task, perform the change on a
parametric assembly, and provide a verification checklist — packaged in the
required `takehome/` layout.

- **CAD system:** FreeCAD 1.1.x (native `*.FCStd`).
- **Portable format:** every part and assembly is also exported to **STEP**
  (`*.step`) so it opens in SolidWorks / Siemens NX as well.

## The task in one line

The rigid flange coupling must transmit more torque within the same envelope, so
the bolted joint goes from **4 bolts to 6 bolts** on the same 90 mm PCD — driven
**parametrically** by a single `bolt_count` value. Full brief in
[`takehome/task.txt`](takehome/task.txt); acceptance in
[`takehome/checklist.txt`](takehome/checklist.txt).

## Package layout

```
takehome/
├── task.txt            # the assignment task (why + what + constraints)
├── checklist.txt       # verification checklist (tolerant of valid variants)
├── Defective/          # empty (per spec)
├── Before/             # the original model — 4 bolts
│   ├── input.FCStd         # top-level assembly (links the parts)
│   ├── input.png           # screenshot
│   ├── input.step          # STEP export
│   ├── flange_half.FCStd   # parametric part + .step
│   ├── bolt_m10.FCStd      # part + .step
│   └── nut_m10.FCStd       # part + .step
└── After/              # the solution — 6 bolts
    ├── solution.FCStd
    ├── solution.png
    ├── solution.step
    └── ... same parts ...
```

## Reproducing the model

The whole package is generated by script (parametric end to end):

```bash
# needs FreeCAD 1.1.x installed, plus python3 + numpy + matplotlib
./scripts/make_takehome.sh
```

- `scripts/build_coupling.py` — FreeCAD script; builds the parametric parts and
  the assembly for a given `bolt_count` (4 for *Before*, 6 for *After*), exports
  FCStd + STEP + a mesh.
- `scripts/render_png.py` — renders the isometric screenshots from the mesh.
- `scripts/make_takehome.sh` — runs both and zips `takehome.zip`.

## Why this is a valid 2–6 hour task

It is a real requirement change (more torque, fixed envelope), not a trivial
dimension edit: the engineer must re-work the bolt pattern on both mating
flanges, keep the two halves aligned and symmetric about the keyway, re-populate
bolts and nuts, keep everything else frozen, and ensure the model still rebuilds
parametrically with no broken references.
